### 기술
- Vercel에 배포하는 Nuxt 3 + TypeScript 앱. 페이지와 server/api를 한 앱에 둔다.
- 저장소는 Turso. 접속 정보는 서버 환경 변수에만 둔다.
- PC와 모바일 반응형.

### 보안
- 로그인 유지는 httpOnly 쿠키.
- 비밀번호는 해시만 저장한다.
- 이메일 보안코드는 8자리 난수다. 별도 페이지에서 제한 시간 안에 맞으면 인증된다.

### 계정
- 회원가입: 이메일, 비밀번호.
- 로그인: 이메일/비밀번호, 또는 이메일 보안코드 인증 후 세션.
- 비밀번호 변경: 이메일 보안코드 인증 후 새 비밀번호 저장.

### 메모
- 본문은 마크다운으로 저장하고, 편집 화면은 위지윅.
- 추가, 수정, 삭제.
- 수동 저장과 주기적 자동 저장. 저장 중에도 입력은 막지 않는다.
- 화면에 저장 중, 저장됨, 실패, 충돌을 표시한다.
- 충돌 시 서버의 마지막 저장본 또는 현재 편집본 중 사용자가 고른다.

### 태그
- 계정마다 태그 목록이 있다. 추가, 이름 수정, 삭제.
- 메모와 태그를 연결하고 끊을 수 있다.
- 이름 수정은 연결된 메모에 함께 반영된다. 삭제하면 연결도 없어진다.

### 필터
- 조건은 포함 태그, 제외 태그, 키워드.
- 조건을 저장하고, 저장된 조건마다 메모 목록을 본다.

### 외부 서비스
- Vercel
- Turso
- Naver Mail POP3/SMTP
